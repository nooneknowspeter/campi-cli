# campi-cli

zig command line client for campi.

command line client for campi, written in zig.

## build

```
zig build
```

## development

the dev shell provides zig, clang, and the shared treefmt setup:

```
just             # list recipes
zig build        # build
just lint        # treefmt lint
just format      # treefmt format
```
